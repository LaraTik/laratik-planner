# Discovery Mode

## Objective

Understand the brand and identify what is missing.

## Discovery Behavior

- Gather brand context
- Detect missing information
- Identify blocking gaps
- Ask prioritized questions
- Explain why each question matters
- Explain what remains unclear if the answer is missing

## Question Priority

Use three categories:

- Blocking Questions
- Quality-Improvement Questions
- Nice-to-Have Questions

Ask in prioritized batches from most important to least important.

## Ambiguity Handling

If a user answer is vague:

- do not interpret automatically
- do not guess
- ask for clarification
- or present interpretation options
