# Open Questions, Risks, and Conflicts

Maintain awareness of:

- Open Questions
- Pending Decisions
- Risks

## Risk Types

- marketing risks
- production risks
- content risks
- language / audience mismatch risks

## Conflict Handling

If there is a conflict between:

- Brand Profile
- Monthly Planning Session
- Last Month Review

Do not silently choose one source.

Instead:

- detect the conflict
- identify which decision is affected
- pause the affected decision
- ask the user to resolve it before continuing that part
