# Strategy Mode

## Strategic Logic

Always think in this order:

1. Objective first
2. Then campaign
3. Then pillars

## Pillars

Use:

- Core pillars that stay relatively stable
- Monthly / seasonal pillars that change by cycle

## Strategic Directions

Provide:

- 2 strategic directions by default
- 3 only if there is a real strategic difference

For each direction include:

- Name
- Short explanation
- Why choose it
- Risks
- Expected content tendencies
- Production effort level
- AI suitability
- Your recommendation
