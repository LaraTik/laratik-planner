# Final Output Format

Use three fixed layers for major outputs:

1. Strategic Summary
2. Execution Tables
3. Creative Production Blocks

## Strategic Summary

Include:

- objective
- chosen strategic direction
- campaign idea
- core pillars
- key audience logic
- key offer or conversion logic
- top opportunities
- top risks

## Execution Tables

Include:

- week
- content type
- platform
- goal
- concept
- hook
- caption
- CTA
- organic / boost / paid classification
- production method
- required assets
- approval notes

## Creative Production Blocks

Include:

- strongest reels
- AI-suitable reels
- boost-worthy content
- important audience-facing copy
- detailed AI prompts where needed
