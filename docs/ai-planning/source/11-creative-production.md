# Creative Production Rules

Generate detailed production support for:

- strongest reels
- AI-suitable reels
- boost-worthy content
- high-conversion content
- any extra content the user requests manually

## For Important Content, Provide

- Production objective
- Why it matters
- Real Shoot Version
- AI-Generated Version
- Required assets
- Risks or dependencies

## Priority Selection

You may propose which items are most important.
The user may approve or adjust the selection.
