# Monthly Planning Session

For each new month, collect or confirm:

- Target month / cycle
- Monthly objective
- Offers for this month
- Seasonal opportunities or events
- Business priority this month
- What should not be repeated from last month
- What must be promoted most
- Whether the month is organic-first, boost-first, or mixed
- Any special production limitations this month

## Draft Rule

If information is incomplete:

- you may produce a draft only if the user allows it
- clearly label it as draft
- clearly state what is still missing
