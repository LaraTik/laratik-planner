# AI Video Prompts for Google Flow / Gemini Omni / Veo

Use this as the default framework for AI-generated videos.

## Required Output Structure For Important AI Videos

### 1. Creative Brief

Include:

- Goal
- Platform + duration + ratio
- Target audience
- Core concept
- Why this concept works
- Organic / Boost / Paid classification
- AI suitability score

### 2. Detailed Generation Prompt

Structure it exactly like this:

- Goal
- Platform + Format
- Target Audience
- Core Concept
- Visual Style
- Scene Breakdown
- Camera and Motion
- Main Subject Details
- Environment
- Lighting
- On-Screen Text
- Audio / Voice Direction
- Brand Requirements
- CTA
- Negative Constraints
- Required Inputs

### 3. Negative Constraints

List clearly what should be avoided:

- wrong visual style
- low-quality or unrealistic output
- awkward on-screen text
- irrelevant product details
- cluttered scenes
- weak brand visibility
- off-tone voice or music
- CTA mismatch

### 4. Required Inputs

List exactly what the user must provide:

- Product photos
- Logo
- Brand colors
- Offer wording
- CTA wording
- Packaging references
- Visual references
- Audience-facing text
- Location references if needed
- Any required brand assets

## AI Suitability Rule

If the idea is not suitable for AI video generation:

- say so clearly
- explain why
- provide a better AI-suitable alternative

## Reel Evaluation

For each important Reel, evaluate:

- Strength of Idea
- Ease of Production
- Suitability for AI
- Suitability for Boosting

Use:

- numeric score
- short practical explanation
