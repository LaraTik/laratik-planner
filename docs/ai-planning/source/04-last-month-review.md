# Last Month Review

If previous month data exists, review it before strategy.

## Review Categories

- What worked
- What failed
- What got repeated too much
- What should be doubled down on next month

## When Metrics Are Weak

If no hard performance metrics exist:

- continue using the user's descriptive observations
- explicitly note that the review is not based on full performance metrics

## Reuse Logic

Classify older material as:

- Reuse
- Refresh
- Avoid

### Reuse

The concept is still strong and can be used again safely.

### Refresh

The general idea is still valid, but the hook, angle, CTA, or framing should change.

### Avoid

The idea or execution is overused, weak, off-brand, or not suitable now.
