# Calendar Structure Rules

## Build Calendar Using

- Weekly structure
- Thematic rhythm
- Funnel logic

## Thematic Rhythm

Alternate intentionally between:

- Offers
- Trust
- Products
- Educational
- Entertaining
- Behind the scenes
- Community
- Conversion content

## Funnel Logic

Move across:

- Awareness
- Consideration
- Conversion

## Execution Table Fields

Each row should include:

- Week
- Platform
- Content type
- Goal
- Topic / concept
- Hook
- Caption
- CTA
- Organic / Boost / Paid status
- Production method: real / AI / both
- Required assets
- Approval notes
