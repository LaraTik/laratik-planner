# API surface reference

> Human-readable reference for every route handler in
> `src/app/api/**/route.ts`. The authoritative contract is the
> source file — when this document disagrees with a route, the
> source wins and the doc is the bug.
>
> **Source of truth:** `src/app/api/` (27 `route.ts` files, 26
> route groups as listed below). One row per route group. The
> NextAuth catch-all expands to the standard
> `/api/auth/{signin,signout,callback/:provider,session,csrf,providers,verify-request}`
> sub-paths.
>
> **Auth gate** uses the following short codes — see
> [`docs/architecture/authorization.md`](../architecture/authorization.md)
> for the full policy:
>
> - `nextauth` — any signed-in session.
> - `nextauth + workspace_manager` — session + manager role on the workspace named in the body / path.
> - `nextauth + agency_admin` — session + agency admin.
> - `nextauth + role` — session + one of the platform roles.
> - `signed-token` — short-lived token issued by the matching sign route; no session.
> - `cron-secret` — `Authorization: Bearer <CRON_SECRET>`; timing-safe.
> - `public` — no auth.
> - `dev-only` — `NODE_ENV !== "production"`; 404 in prod.

## Conventions

- **All POSTs accept JSON** unless the body is a raw `Buffer` (uploads) or form-data (NextAuth catch-all). The bootstrap admin route accepts both for the first-time setup form.
- **Errors are JSON** with the shape `{ error: string, code?: string }` (or `{ error, issues }` for Zod validation failures). The social OAuth callbacks redirect to the workspace's channels page with an `?error=…` query param instead.
- **Rate limits** are scoped per route (`scope: …`). The `enforceRateLimit` helper resolves the subject from `session.user.id` by default, except `bootstrap` which uses the client IP. The scope names are listed in the Rate-limit column above; the window/limit lives in `src/lib/security/rate-limit.ts`.
- **Cron routes** are not behind NextAuth — they require `Authorization: Bearer <CRON_SECRET>` with a timing-safe compare (`src/lib/security/rate-limit.ts` does the compare; `scripts/vps/*.sh` are the callers).
- **Dev-only routes** are guarded twice: the proxy allowlist and the route handler both check `serverEnv.NODE_ENV === "production"`. Production builds return 404.

## Schema files

The Zod schemas referenced above are in `src/lib/validation/` (one per domain) and inline at the top of each route file. Search for `safeParse(await req.json()` to find them. The body shapes listed in the table above are the public contract — additions to the schema that change the response shape require a major-version bump and a CHANGELOG entry.
