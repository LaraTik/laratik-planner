LaraTik State Principles

Operational states must respect the user's focus. Fallbacks provide immediate semantic clarity and an explicit path forward without alarming the user.

  • check

    Explanatory Title (Sentence Case)

    State what occurred directly without dramatic exclamation points or ambiguous codes.

  • check

    Humane Message without Jargon

    Translate technical stack traces into agency operations impact (e.g., assets preserved).

  • check

    Single Dominant Next Action

    Only one primary filled action button per container to eliminate decision fatigue.

  • check

    Non-Destructive Escape Hatch

    Secondary actions offer audit exports, log inspection, or return to safe states.

  • check

    WCAG AA Contrast Compliant

    #172033 on #FFFFFF yields a 14.8:1 ratio, significantly surpassing 4.5:1 requirements.
