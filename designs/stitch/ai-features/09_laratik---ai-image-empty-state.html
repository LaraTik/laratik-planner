Stitch MCP — how to import these designs

The HTML files in this directory are stand-ins. To import them into the live Stitch project 5403097764334458790, open each one in a browser, screenshot the rendered page at 2560px, and use Stitch's "Upload design" → "Replace screen" flow. The screens are sized for the desktop 1440px breakpoint; tablet (1024px) and mobile (390px) breakpoints are out of scope for v1. See docs/visual-parity/MCP.md for the full recipe.
