Set up YouTube Data API v3

YouTube's official API. Free for 10,000 units per day, which is plenty for trend extraction. This guide walks you through getting a key and wiring it into laratik-planner.

1

What this source gives you

YouTube surfaces three kinds of trend signals that are useful for social-media planners:

  • Trending topics — the top 30 trending videos in any region, refreshed every 15 min.
  • Emerging creators — channels with rapid subscriber growth in your verticals.
  • Format signals — vertical shorts, long-form essays, podcast-style videos — useful as format references for your Reels and TikToks.

Example of a signal that lands in your Trends feed:

2

Free vs paid

YouTube's Data API v3 uses a unit-based quota. The default is generous.

Plan Quota Cost Enough for…
Free (default) 10,000 units / day $0 ~1,100 trend extractions / day
Paid extra +1M units / day on request $7 / 1M extra units Multi-region + high-frequency use

info Each trending-videos call costs ~5 units. Each channel search costs ~100. laratik-planner uses 1,500–2,000 units/day on a typical 6-hour cadence.

3

How to get a key

Takes about 5 minutes. You'll need a Google account.

  1. a
    Create a project in Google Cloud Console
    Open console.cloud.google.com → New project → name it "laratik-planner trends".
    imageScreenshot: New project dialog
  2. b
    Enable the YouTube Data API v3
    Library → search "YouTube Data API v3" → Enable. Wait for the green checkmark.
    imageScreenshot: API library with YouTube Data API v3 enabled
  3. c
    Create an API key credential
    Credentials → Create credentials → API key. Restrict it to "YouTube Data API v3" (recommended for safety).
    imageScreenshot: Create API key dialog
  4. d
    Copy the key into laratik-planner
    Back in this app, paste the key into the field below. It is encrypted at rest with workspace-scoped KMS.

Common errors and fixes

Error code Likely cause Fix
400 · API key not valid Key was deleted, regenerated, or restricted to the wrong API. Re-paste the key from Cloud Console. Make sure restrictions allow YouTube Data API v3.
403 · quotaExceeded You hit the 10K unit / day cap. Wait until midnight Pacific, or request a quota increase from Cloud Console.
403 · accessNotConfigured YouTube Data API v3 is not enabled in your project. Cloud Console → Library → YouTube Data API v3 → Enable.
404 · videoNotFound A video was deleted between extraction and analysis. Nothing to do — laratik-planner auto-skips and retries next cycle.
500 · backendError YouTube-side issue (rare). laratik-planner retries with backoff (max 3x). Check Google status dashboard if persistent.
6

What to do when the source breaks

  1. a Check the health dashboard. Go to Trends → Sources → Health. Look at the success rate over the last 24h. Below 95% means something is off.
  2. b Run a single test. Click "Test connection" in step 4 above. The error code from this test maps directly to a row in step 5.
  3. c Still broken? Reach out. Use the in-app help → "Contact support". Include the workspace ID and the timestamp of the first failure — we'll pull the logs.
